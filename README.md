
# 💼 Wallet — Personal Finance App

A beautifully designed personal finance tracker app for Android.
Track your income, expenses, loans, and savings — all in one place.

---
---

## ✨ Features

- 💰 Track income, expenses, lent money, and received payments
- 📊 Visual charts and monthly breakdowns
- 📅 Calendar view to see daily transactions
- 🔍 Search and filter transaction history
- 🌙 Dark mode UI
- 💾 Data saved locally on device
- ⚡ Fast and lightweight — built with WebView

---

## 🛠️ Built With

- **Kotlin** — Android development
- **WebView** — renders the UI
- **HTML / CSS / JavaScript** — frontend interface
- **localStorage** — local data persistence
- **Android Jetpack** — Splash Screen API

---

## 🚀 Getting Started

### Prerequisites
- Android Studio (latest version)
- Android device or emulator (API 21+)

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/YOURUSERNAME/wallet-app.git
   ```
2. Open in Android Studio
3. Build and run
   ```
   Build → Clean Project → Rebuild → Run
   ```
